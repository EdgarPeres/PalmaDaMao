# ADR 0004 — Mobile First e PWA

## Status
Aceito

## Contexto
O público principal acessará o portal pelo celular.

## Decisão
Projetar todas as telas mobile first e implementar PWA desde o início.

## Consequências
- Melhor experiência em smartphones
- Possibilidade de instalação sem app store
- Maior valor percebido pelo usuário final
